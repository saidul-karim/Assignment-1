## Overview

The assignment demonstrates practical knowledge of core TypeScript concepts, including:

1. Basic types and union types
2. Optional and default parameters
3. Type narrowing using `typeof`
4. Readonly tuples
5. Generics and rest parameters
6. Interfaces
7. Object-Oriented Programming (OOP)
8. Access modifiers
9. Promises and asynchronous programming


All coding solutions are implemented in a single file named `solutions.ts`.
